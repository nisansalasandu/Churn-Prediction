
# 📊 **Customer Churn Prediction using Machine Learning**

This project predicts whether a telecom customer will **churn** (leave the company) or **stay**, using machine learning classification models.
The dataset used is **churn-bigml-20.csv**, which includes customer details such as call usage, plans, and customer service calls.


## 🛠️ **Tools & Libraries Used**

* **Python**
* **pandas**, **NumPy**
* **scikit-learn**
* **matplotlib**, **seaborn**
